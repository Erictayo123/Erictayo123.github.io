Overview

TinyDrowsy ESP32 is an end-to-end AI system for real-time drowsiness detection running on the ESP32-S3 microcontroller. The system uses a lightweight Convolutional Neural Network (CNN) to classify eye states (open/closed) from camera input, enabling driver monitoring without cloud connectivity.

Figure 1: High-level system architecture

Key Metrics

  • 10.6K Parameters
  • 99.87% Accuracy
  • 27.4KB Memory Footprint
  • 16ms Inference Time
  • 8.8 FPS Throughput

The system addresses the challenge of running neural networks on resource-constrained edge devices through careful model design, quantization, and hardware optimization.

Dataset

The dataset combines public resources and self-captured images to ensure robust performance under diverse lighting conditions.

Data Sources

  • Public datasets: DRIVER dataset, CEW (Closed Eyes in the Wild)
  • Self-captured: 5,000+ images across different lighting conditions, camera angles, and participants
  • Augmentation: Rotation, brightness adjustment, contrast variation, and noise injection

# Dataset preprocessing
def preprocess_image(image):
    # Resize to 48x48

    # Convert to grayscale
    image = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    # Normalize to [0, 1]
    image = image.astype(np.float32) / 255.0
    # Add channel dimension
    image = np.expand_dims(image, axis=0)

Design Decisions

  • Depthwise separable convolutions reduce parameters while maintaining accuracy
  • BatchNorm + ReLU for faster convergence and better generalization
  • Dropout (0.3) prevents overfitting with limited dataset
  • Input size: 48x48 balanced between detail and compute

Quantization

To fit within the ESP32's memory constraints, the model was quantized from FP32 to INT8 using ESP-PPQ (ESP32 Post-Training Quantization).

Quantization Pipeline

# ESP-PPQ quantization
from esp_ppq import quantize

quantized_model = quantize(
    model,
    calibration_data,
    target='esp32-s3',
    precision='int8',
    method='symmetric'
)

# Export to TFLite micro format
quantized_model.export('tinydrowsy_quantized.tflite')

Figure 8: FP32 vs INT8 performance comparison

Results

  • Memory reduction: 83.2KB → 27.4KB (67.1% reduction)
  • Accuracy drop: 99.87% → 99.81% (0.06% loss)
  • Inference speedup: 2.3x faster

Deployment

The quantized model was deployed on the ESP32-S3 using ESP-IDF with a custom camera pipeline.

Hardware Setup

  • MCU: ESP32-S3 with 512KB SRAM
  • Camera: OV2640 with 2MP resolution
  • Interface: 8-bit parallel camera bus
  • Power: 5V USB or LiPo battery

Inference Loop

// Main inference loop
void inference_loop() {
    while (true) {
        // Capture frame
        camera_fb_t *fb = esp_camera_fb_get();
        if (!fb) {
            ESP_LOGE("Camera", "Frame capture failed");
            continue;
        }

        // Preprocess image (48x48 grayscale)
        preprocess_frame(fb->buf, fb->len);

        // Run inference
        float* output = tinydrowsy_infer(preprocessed_data);

        // Post-process and classify
        int prediction = argmax(output);

        // Update state
        update_drowsiness_state(prediction);

        // Free buffer
        esp_camera_fb_return(fb);

        // 16ms inference time gives ~62.5 Hz throughput
        vTaskDelay(10 / portTICK_PERIOD_MS);
    }
}

Performance Optimization

  • PSRAM: Allocated camera buffers in PSRAM to free SRAM for model
  • DMA: Used DMA for camera data transfer
  • Model placement: Model stored in Flash with cached execution
  • Frame skipping: Process every 3rd frame to maintain real-time performance

Field Testing Results

The system was tested under various conditions including:

  • Daylight: 99.9% accuracy
  • Night/Indoor: 98.5% accuracy (with IR illumination)
  • Glasses/Sunglasses: 97.8% accuracy
  • Different skin tones: 98.2% accuracy

Figure 14: Field test results under different conditions

Known Limitations

  • Performance degrades in extreme low-light conditions
  • Requires face to be relatively centered in frame
  • Does not detect drowsiness from yawning or head movement

Conclusion

TinyDrowsy ESP32 demonstrates that high-accuracy neural networks can run effectively on resource-constrained microcontrollers. By combining careful model design, quantization, and hardware optimization, the system achieves professional-grade performance in a compact, low-power package.
